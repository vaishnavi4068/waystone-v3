Waystone v3  vs.  QuantMind Trading API

Two trading systems at different altitudes of the stack — an opinionated momentum application versus crypto-derivatives infrastructure exposed as a REST API. More complementary than competitive.

Sources: Waystone v3 codebase · QuantMind OpenAPI 3.1 v0.5.0 (25 endpoints, 43 schemas)

TL;DR

The brain + safety rails

Waystone v3

An opinionated momentum / trend-following engine. Pluggable signal fusion, a Claude agent control plane, integrated backtesting, and a deliberate paper-only posture. Stocks/ETFs today.

The plumbing

QuantMind API

A multi-tenant, crypto-derivatives-centric data + pricing + execution platform. Instrument catalog, OHLC, BTC/ETH vol surfaces, and hosted strategies running against real exchange accounts.

QuantMind could sit underneath Waystone as a data/execution backend.

What each has that the other lacks

QuantMind has, Waystone doesn't

  • Real options / volatility pricing (vol surfaces, IV)
  • Crypto / perp / future connectivity
  • Live exchange execution with API-key vaulting
  • Multi-tenant SaaS surface (orgs / accounts / RBAC)
  • Versioned public REST API

Waystone has, QuantMind doesn't (exposed)

  • Pluggable signal-fusion architecture
  • LLM sentiment + autonomous agent control plane
  • Integrated backtesting on the live pipeline
  • Explicit paper-only safety guardrail
  • Claude Arena — MCP multiplayer competition

QuantMind endpoint map

Reference data — GET /securities, /securities/{id}, /figi (Open FIGI), /exchanges, /countries
Market data — GET /ohlc/{security_id} (trade/book), /block, /block/headers
Derivatives pricing — GET /vol-surfaces/{asset} (BTC/ETH) · IV bid/ask, forwards, spot inputs  ⭐ standout
Strategy execution — /markets (StrategyMarket CRUD), /markets/schema/{strategy_name}
Accounts & secrets — /accounts, /accounts/{id}/api_keys (exchange key vault)
Tenancy — /user, /user/orgs, /user/tokens, /watchlists

Where they could meet

🔌
QuantMindDataSource implementing the MarketDataSource protocol (/ohlc/{security_id}, /securities) — adds crypto / derivatives data to Waystone.
⚡
QuantMindBroker implementing the Broker protocol against StrategyMarket + accounts — extends execution beyond stocks into crypto / perps.
📈
Vol-surface SignalContributor consuming /vol-surfaces/{asset} — an options-aware signal Waystone cannot produce today.
